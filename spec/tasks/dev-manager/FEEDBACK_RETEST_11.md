# 第十一轮：启动状态、批量 PDF 与设置精简

## 准备

IDEA 设置 → 插件 → 齿轮 → 从磁盘安装 `build/distributions/IJ-Plugin-Java-0.1.0-dev-feedback11.zip`，按提示重启。无需清空 H2，已保存的 API key 保留。首次升级从旧库无法推断以前的启用选择，请手动启用一次；此后记住选择。

若尚未配置：插件右上角齿轮 → 停用 → 服务配置，分别填写生成与嵌入服务的 Base URL、模型及嵌入维度，在对应凭据栏填写 API key 并保存。更换 key 时不要同时勾选移除凭据。使用此前已验证可用的配置；同济接口保持已验证可用的网络环境（此前 VPN 导致 403）。不要把 key 写入本测试记录。

准备两到三个不同的、包含可提取文字的 PDF；另准备一个损坏 PDF 用于失败检查。测试会调用已配置的嵌入服务。

## 逐项验收

- [ ] 启用成功后完全退出 IDEA，再打开：插件自动为启用状态，可直接发送新消息；旧生成任务不自动重跑。
- [ ] 手动停用后完全退出 IDEA，再打开：仍为停用状态，可直接编辑服务配置。
- [ ] 在启用状态点击“导入 PDF”：出现原生文件选择器，可按 Ctrl/Shift 多选 PDF 后一次确认。
- [ ] 等待逐份处理完成：每份 PDF 各有一条资料记录，均为 READY，无同批文件之间的 Conflict；可分别提问验证引用文件及页码。
- [ ] 点击“更换所选”仍只选择一份 PDF，替换目标保持为所选资料。
- [ ] 批量过程中停用，再启用：尚未开始的文件不会继续导入；已经完成的资料保留。可重新选择剩余文件导入。
- [ ] 批量包含损坏 PDF：失败项有明确错误提示，后续文件停止；已成功项保留，可移除失败项并重新选择剩余文件。
- [ ] 批量过程中尝试另一次资料变更：明确拒绝 BUSY，不并行覆盖资料库。等待批量结束后可操作。
- [ ] 打开设置：不再显示“整理历史”“恢复未保存”“关闭标签”；资料管理、服务配置、启用/停用仍可用。
- [ ] 回归代码条与文字混排、同一行中文选字、连续发送两次、流式滚动及文件页码引用。
