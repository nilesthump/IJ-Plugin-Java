## 安装与准备

1. IJ → Settings → Plugins → 齿轮 → Install Plugin from Disk，选择仓库 `build/distributions/IJ-Plugin-Java-0.1.0-dev-feedback2.zip`，重启 IJ。
2. 打开项目和 Course Assistant，右上齿轮 → 服务配置。修改配置前先停用。
3. 生成服务使用生成模型及其 key；嵌入服务使用支持 `/embeddings` 的 embedding 模型及其 key。维度必须按该服务实际支持设置，不从生成模型推断。
4. 新 key 直接填入即可替换。填写新 key 后，删除选项应禁用；勾选删除后，新 key 输入应禁用。留空且不勾删除保持旧凭据。
5. 正常测试请保留两类凭据，确认保存后显示两栏“已保存”，再启用。这只证明本地已保存，不证明远端认证通过。
6. 准备一份可复制文字 PDF，可先使用 `spec/tasks/dev-manager/blackbox-fixtures/course-a-v1.pdf`。不使用扫描件，不清空数据库。
