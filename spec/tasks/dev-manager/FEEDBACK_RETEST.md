## 准备

1. 退出/重启 IJ 前先处理未保存提示，保留需要的聊天资料。不要清空插件数据目录。
2. Settings → Plugins → 齿轮 → Install Plugin from Disk，选择重新交付的 `build/distributions/IJ-Plugin-Java-0.1.0-dev.zip`，按提示重启。仍是同一插件ID/版本名，以本轮交付哈希区分新旧包。
3. 核对 Help → About 为本机已测 `2026.2.3 / IU-262.10968.63`。
4. 打开 Course Assistant，右上角应仅有新建会话、历史会话、搜索会话、设置四个入口；下方只有聊天区和底部 draft。
5. 设置 → 停用 → 服务配置：生成栏保留实际可用的生成配置；嵌入栏必须填写支持 `/embeddings` 的服务、模型和其真实维度。`https://api.deepseek.com` / `deepseek-flash` 是生成配置，不能作为嵌入模型；填 `1024` 不会改变模型能力。生成和嵌入可以使用不同供应商及 API key。Base URL 不包含 `/embeddings` 或 `/chat/completions` 后缀，是否包含 `/v1` 按供应商文档。不要把 key 放入本方案/截图/反馈。
6. 保存后启用。此处只验证本地配置，不代表远端认证或额度已验证。真实导入/提问会使用自己的服务额度。
7. PDF样例：`blackbox-fixtures/course-a-v1.pdf`，共3物理页、第2页空白、第3页答案为17分钟；也准备一份可复制文字的真实PDF。
