# F2-G3：受控候选生成与ReAct接入

负责人：用户本人。依赖：G2通过。状态：NOT_STARTED。

## 工作项

1. 在现有唯一ReAct循环中接入定位/候选工具，保留attempt一次首检、每步完整预算、严格toolCallId配对与课程证据身份。无库不禁用F2，F2异常不套课程通识降级。
2. 使用固定snapshotRef及原始指令生成候选；按推荐提案，每次工具内部至多一次tools=[]模型请求，预算/次数/耗时/输出与取消计入父级，无第二session、递归循环或隐式重试。宿主按原提交/目标/源码/指令修订及范围生成稳定逻辑requestId，不接受模型换toolCallId或自造requestId绕过去重；同请求并发、成功后或失败后重复调用均返回旧结果/状态，不再次订阅生成模型，协议结果仍各自配对callId。
3. 严格解析结构化修改，校验before精确匹配、范围、非重叠块及输出完整性。在固定副本构造after，预览前固定所有正文与哈希；禁止未展示的格式化/优化imports。
4. 工具观察返回有界概要/产物引用。流式只供不可批准预览；父有效分支正常耐久收口才能提升候选，不将课程降级旧分支候选复活。
5. 缺需求追问、无变化、无效候选、超限和开发故障分开处理。F2重新生成只允许用户新SubmitDraft，不由审核按钮/失败处理或retryLatest触发。

## 验证

沿ReactEngineTest/SpringAi模型测试增加合成响应：无课程库仍能生成、课程故障隔离、一次子调用计数、不同callId的同请求重复/并发及错误后再调用不增订阅、预算用尽前拒绝订阅、工具参数分片不提前执行、恶意/越界/重叠修改拒绝、父保存失败/停止不使子候选合格。现有课程问答/引用/中断哨兵全部回归，不调用真实付费模型。

## 退出条件

能从两种输入得到准确完整候选及独立产物；失败/中断资格与上下文/摘要过滤共用；统一All及必要本机模型接线探针通过。合成模型只证明本地协议，不声称真实生成质量。
