## R05只需补清楚的编辑器步骤

Diff“同意并应用”后关闭审核窗口且不再提供同一候选的重复批准，是现有设计；无需再次打开Diff。

1. 若刚批准后还没编辑其他内容，点击IDE中本次修改的examples/Calculator.java编辑区，让光标落在代码中。
2. 执行IDE的“编辑 → 撤消”，一次撤消应恢复候选应用前源码；聊天卡片自动显示已撤销。
3. 执行“编辑 → 重做”，源码恢复候选结果；聊天卡片自动反映恢复。
4. 正常保存，再在方法中加注释；插件自动反映保存与后续编辑，不要求点击核对按钮。

若原候选应用之后已经继续做了其他编辑，不要为了本测试连续撤消旧工作。可等下次自然批准一个新候选后，再做以上动作。重复批准的自动验证已保留；不要求强点已禁用按钮。
