## 安装、凭据和 PDF 准备

1. IJ → Settings → Plugins → 齿轮 → Install Plugin from Disk，选择本轮 ZIP，然后重启。
2. 打开项目/助教侧栏 → 右上设置。修改配置前先停用。
3. 生成服务填写生成模型及对应 key；嵌入服务填写支持 `/embeddings` 的 embedding 模型、实际支持的维度及对应 key。
4. **针对本次 PDF 错误**：日志已定位到 HTTP 请求头字符校验失败，在请求发出前发生。请先在嵌入服务栏重新复制纯 API key，不附带说明文字、引号、空格或换行。直接填新值可替换，不勾选删除；确认保存。
5. 再启用。若新提示指出生成或嵌入 key 含非法字符，按所指栏重新填写。不要把 key 发到聊天中。校验通过只代表字符合法，不证明认证成功。
6. 准备可复制文字 PDF，例如 `spec/tasks/dev-manager/blackbox-fixtures/course-a-v1.pdf`；设置 → 导入 PDF → Windows 文件选择窗口选择文件。不要删除数据库或已有资料。
