# 用户关于托管资料与完整恢复的答复

来源：当前 Codex 会话的用户问答，2026-10-16（Asia/Shanghai）。协调代理逐字转录；原始身份与授权以会话为准。

## 问题一

导入课程 PDF 后，插件是否保存一份托管副本？保存副本可让原文件移动或删除后，历史回答仍能打开对应版本和页码。

## 答复一

保存托管副本，引用对应导入版本（推荐）

## 问题二

重启 IDEA 后，是否恢复每个 session 的待发送文字、代码片段，以及原先打开的标签、顺序和当前标签？

## 答复二

草稿和标签布局全部恢复（推荐）

## 确认范围

导入课程 PDF 保存托管副本，历史引用对应导入版本；重启后恢复各 session 的待发送文字、代码片段，以及原先打开的标签、顺序和当前标签。具体存储产品、目录、保存频率、崩溃恢复算法与标签关闭行为未因本次答复自动确认。
