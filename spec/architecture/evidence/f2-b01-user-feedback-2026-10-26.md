## 安装与准备

1. IDEA 设置 → 插件 → 齿轮 → 从磁盘安装：`H:\IJ-Plugin-Java\build\distributions\IJ-Plugin-Java-0.1.0-dev-f2-g6.zip`，按提示重启。包哈希及本地验证记录见 [G6_IMPLEMENTATION](G6_IMPLEMENTATION.md)。
2. 保留现有 H2、聊天与凭据，无需清库或重填 key。使用此前验证可用的生成/嵌入配置；需改配置时先停用。key 只填插件凭据栏，不放入聊天、截图或验收记录。
3. 新建一个临时 Java 工程，把 [samples/src](samples/src) 中两个包复制到工程的 `src` 下，并将该目录标为 Sources Root。等 IDEA 索引完成。不要直接拿工作源码做验收样例。样例故意保留错误，不需要运行代码。
4. 主文件 `src/demo/Calculator.java`，重名文件 `src/other/Calculator.java`。每个独立用例开始前恢复对应样例；需要新候选时新建聊天或明确重新发送 draft。模型生成质量取决于用户配置的真实服务，下面发送动作会调用该服务；代理未代为调用付费模型。
5. 打开 Course Assistant Tool Window，启用插件。已有课程库可保留；无库的独立场景可用干净测试环境，不要为测试删除现有课程资料。
