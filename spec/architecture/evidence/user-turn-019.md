# 用户关于检索降级、关闭标签与单会话任务的答复

来源：当前 Codex 会话用户问答，2026-10-16（Asia/Shanghai）。协调代理逐字转录；原始身份与授权以会话为准。

## 问题一

课程检索发生故障并提示用户后，当前问题应怎样继续？（正常检索无命中会单独区分。）

## 答复一

自动继续通识回答，明确标注课程检索失败、未使用课程证据（推荐）

## 问题二

关闭一个正在生成回答或整理上下文的 session 标签时，当前任务怎样处理？关闭标签本身不删除聊天记录。

## 答复二

只关闭标签，任务继续；可从会话列表重新打开（推荐）

## 问题三

同一 session 正在生成回答或整理上下文时，再次发送问题应怎样处理？切到其他 session 仍可独立提问。

## 答复三

每个 session 一次只执行一个任务；新内容留在草稿，完成后再发送（推荐）

## 确认范围

实际使用的课程检索故障提示后自动转为明确标记的通识回答；这不改变开发时暴露错误的原则，也不等于课程库未建立或正常无命中的默认行为已确认。关闭标签仅关闭视图，任务继续，聊天不删除且可从会话列表重开。同一 session 一次只执行一个任务，忙时新内容保留为草稿，完成后由用户再发送；不同 session 可独立提问。具体任务身份、取消与提交算法仍为实现提案。
