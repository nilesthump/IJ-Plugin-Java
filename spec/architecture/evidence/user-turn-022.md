# 用户确认方法全文与类结构的上下文组合

来源：当前 Codex 会话用户问答，2026-10-16（Asia/Shanghai）。协调代理逐字转录；原始身份与授权以会话为准。

## 问题

“对应方法和类”先按选区所在的方法及所属类理解；待发送区应自动附加哪种正文？完整类通常已经包含该方法。

## 答复

方法全文＋类声明和字段等结构信息，保留原选区（推荐）

## 确认范围

保留原选区，自动补充选区所在方法全文及所属类的声明、字段等结构信息。自动补充先进入同一 session 的待发送区，随问题提交；消息/快照持久化、单 session 任务和预算约束继续适用。本条没有要求附加整个类的所有方法实现、跨文件调用图或整项目源码。
