# F0 课程资料视图与版本管理

更新：2026-10-18（Asia/Shanghai）。user-turn-032 确认 MD5 排重，user-turn-033 更正为在课程资料视图选中具体资料进行更换/移除，替代原 chapter 替换规则。H2/JVector、托管 PDF 副本沿用既有确认。以下版本算法、历史保留和清理为代理提案，未实施或冻结。

## 1. 课程资料视图（入口已确认，布局提案）

提供共享课程库的资料列表，首版显示资料名称、当前版本/导入时间、处理状态和可得页数；支持导入 PDF，点击选择一项后执行“更换”或“移除”。不要求用户先创建 course/chapter，也不从文件名猜测替换目标。

更换/移除动作开始时固定 documentId、expectedSourceVersionId 和资料修订号；documentId 即稳定资料身份，不能按当前行号、文件名或异步完成时的选中项定位。操作期间选中另一项不改变既有任务目标。按钮状态与核心入口均校验目标存在、版本/修订和操作状态。

| 对象 | 角色 |
| --- | --- |
| CourseDocument / documentId | 视图中的稳定资料项；改名或更换文件不改变身份 |
| ManagedBlob | 托管 PDF 固定字节及 MD5；MD5 用于重复排除，不代替资料身份 |
| SourceVersion | 某资料的一版固定 PDF 字节；历史引用绑定版本，不跟随当前活动指针漂移 |
| CorpusGeneration | 固定资料活动版本集合、嵌入空间和索引配置，保证图及证据映射一致 |

## 2. 导入与 MD5 去重（用户选择，算法提案）

选择文件后复制到托管暂存区，对固定副本计算 MD5，再原子查重/登记；后续解析始终消费同一副本。新导入命中已有就绪资料时提示重复并定位已有资料，不再生成重复 blob/资料或向量。处理中、失败、已移除或仅有托管原件的记录要显示真实状态，不能只因 MD5 存在就宣告可检索。

更换命中所选资料当前活动版同 MD5 且派生配置就绪时返回“内容未变化”，不产生新源版本；若处理/嵌入配置改变或结果不完整，另按明确的索引准备流程处理，不能将 MD5 命中当作派生数据已就绪。命中其历史旧版本但当前活动版不同，按更换流程复用旧版本并发布；命中另一资料的字节时可复用 blob，但保留本次选中的 documentId 并建立其版本关联，不误更换另一资料。动作绑定和字节去重是两项独立责任。

复用前检查托管实体仍有效、派生结果完整。分页/向量仅在字节、处理配置、嵌入空间和实际嵌入正文兼容时复用；资料标签参与正文时不能无条件共用向量。可复用字节或数值，但各资料/sourceVersion 的来源身份和证据映射独立。并发导入不能把相同字节登记成两份 blob，无法复用时如实报错或按显式处理流程执行。

## 3. 更换选中资料（入口已确认，发布算法提案）

为动作开始时固定的 documentId 选择新 PDF。先完整保存副本，准备分页、片段/嵌入和包含该资料新版的检索代次，其他资料有效结果复用；JVector 不可变图仍可能需要重建，不将其成本忽略。

短提交同时检查资料仍可用、预期活动版/修订和库基准未变、任务未取消，再共同切换该资料活动版本与匹配的课程库代次。候选未就绪、失败/取消或并发操作改变了基准时不覆盖旧版，不自动把迟到候选发布到新的选中项。移除与更换竞争时，已失效的更换不能使资料复活；图/向量/ordinal映射不匹配时不宣告成功。不同资料并发发布也校验库基准；基准已变需重新准备，不能用旧活动集合覆盖另一资料已发布的更新。

attempt 建立时固定课程库代次（无激活库也固定为无库状态），首次检索和全部 ReAct 课程工具均使用同一快照；新 attempt 才读取替换/移除后的活动集合。恢复中等待该固定代次，不能中途改取最新库。在途与历史回答仍引用固定 sourceVersionId/chunkId/物理页，PDF 和来源标签不被新版覆盖。

## 4. 移除与清理（移除入口已确认，其余为提案）

- 移除命令固定所选 documentId 与预期修订，从后续检索活动集合移出该资料，并发布匹配的新代次；不删除 session，不误移除当前新选中的其他资料。
- 移除过程/失败明确显示；未共同提交资料目录和代次时不宣称已完成。旧在途检索快照及历史引用所需的原版本保留。
- 旧回答/过程记录引用的 PDF 版本继续可按原页打开；“移除”与彻底清理托管字节分开，不能用索引清理顺带删除历史来源。
- 首版不静默按容量淘汰。提供显式“清理未引用旧版本”入口并预览；只处理非活动、全库无引用、无在途任务/handle占用的版本。共享 blob 最后一个关联/引用释放后才删除。
- 数据库与旁存文件清理不一致时提示未完成，停止受影响清理；保留必要身份用于继续处理，不伪造成功或清空整个库。

详细验收及排期继续待定。本稿不把课程分类、自动分析章节或跨机器同步加入首版要求。
